# WheelPicker

Колесо запуска приложений для Windows 11 с оформлением в стиле системы. Работает самостоятельно; интеграция с PowerToys Run устанавливается по желанию.

![WheelPicker: выбор приложения, группы и внешние действия](docs/demo.gif)

Анимированная демонстрация реального интерфейса на примере системных приложений.

## Установка

1. Скачайте **Setup.exe** из раздела [Releases](../../releases).
2. Запустите установщик и выберите автозапуск, ярлык и интеграцию с PowerToys Run, если он установлен.
3. Откройте настройки WheelPicker через меню «Пуск» или значок в трее. После установки адаптера перезапустите PowerToys.

Для установки достаточно одного Setup.exe. Git, исходники, SDK и подключение к интернету не нужны. Требуется 64-разрядная Windows 11 с .NET Framework 4.8. Права администратора не запрашиваются. Установщик пока не имеет цифровой подписи.

Приложение устанавливается в `%LOCALAPPDATA%\Programs\WheelPicker`. Повторный запуск нового установщика обновляет приложение. Удаление — через «Параметры → Приложения → Установленные приложения». Личные настройки сохраняются при обновлении и удалении в `%LOCALAPPDATA%\WheelPicker`.

## Как работает

- Удерживайте **~ / Ё**, наведите курсор на программу и отпустите клавишу. Клавишу или сочетание можно изменить в настройках.
- Отпускание в центре и Esc отменяют выбор. Есть также режим открытия щелчком.
- Точка у значка обозначает открытое приложение. Внешние секторы позволяют открыть его повторно или закрыть окна. У Проводника — открыть новое окно или закрыть все окна папок.
- «+» добавляет программу. В выборе приложений разделены локальные программы и Microsoft Store; можно указать файл или ярлык.
- Группы объединяют до **3 приложений** в одном секторе. Создайте группу и перетащите в неё уже добавленные программы или добавьте новые. Внутри группы работают те же действия открытия и закрытия; повторное добавление одного приложения блокируется.
- Настраиваются задержка появления, расположение, тема и запас области выбора внешних секторов. Есть предпросмотр границ, перестановка программ мышью и импорт/экспорт настроек.
- В PowerToys Run доступны команды **wheel** и **wheel settings**. Адаптер собран для PowerToys 0.101 / .NET 10; при изменении API может потребоваться пересборка.

Закрытие отправляет обычный запрос окнам: приложение может предложить сохранить документ. Принудительное завершение пользовательских программ не используется.

## Сборка

Исходники написаны на C# / WPF для .NET Framework 4.8. Скрипты используют системный компилятор Windows, без .NET SDK и сторонних библиотек.

```powershell
# Только самостоятельное приложение:
.\Build.ps1 -SkipPlugin

# Приложение и адаптер — нужны библиотеки установленного PowerToys:
.\Build.ps1 -PowerToysPath (Join-Path $env:LOCALAPPDATA 'PowerToys')

# Установщик — нужен Inno Setup 6.7.3 или новее:
.\Build-Setup.ps1 -CompilerPath 'C:\Tools\Inno Setup 6\ISCC.exe'
```

Последняя команда создаёт Setup.exe и файл SHA-256 рядом с папкой проекта. Сборщик установщика: [Inno Setup](https://jrsoftware.org/isinfo.php).

```powershell
.\Test.ps1
.\Test-Setup.ps1 -CompilerPath 'C:\Tools\Inno Setup 6\ISCC.exe' -TestDirectory 'C:\Temp\WheelPicker-Setup-Test'
```

Тесты приложения используют отдельные настройки и тестовые окна. Тесты установщика создают изолированную установку и отдельную запись удаления: проверяют установку, обновление, удаление, ярлыки и сохранность настроек. Для повторного запуска выберите новую тестовую папку.

`src/` — приложение и проверки; `tests/` — вспомогательные тестовые процессы; `PowerToysRun/` — адаптер; `setup/` — сценарий установщика. Сгенерированные файлы и пользовательские настройки не включаются в Git.
