# Pixel pets

`cat-run.png` is an original generated sprite sheet used by the optional inner-ring cat in WheelPicker 1.5.1. It is embedded into the EXE, so no image download or separate asset installation is needed. Eight frames form one running cycle; the cat travels clockwise in eight seconds, stays upright, and mirrors to follow its direction. Rendering stops when the wheel closes. Settings thumbnails are static.

The default orbit is eight seconds at 1×; speed is configurable from 0.25× to 3×. `cat-idle.png` has four front-facing blink poses. `bat.png` has four wing-flap poses in its top row and four stationary blink poses in its bottom row. Both pets pause on hover, blink, show a flashing native yellow pixel question mark, and continue from the same point after mouse leave. Animal choice is independent of theme; the automatic mode uses the bat in Halloween.

Generated with the built-in `image_gen` tool from a user-provided ginger pixel-cat reference. No external pet service or browser data is used. Layout: four columns, two rows; source dimensions 1774×887. `OrbitCat.cs` applies a shared crop and baseline offsets with nearest-neighbor scaling.

Generation prompt:

> Create a production sprite sheet for a small running cat UI animation. The attached image is the character identity and pixel-art style reference: cute ginger/orange cat, dark brown stepped pixel outline, pale cream muzzle/chest and paws, pink inner ears, black bead eyes, upright curled orange tail with a pale tip. Preserve its recognizable identity and small crisp blocky pixel-art look, but change the sitting pose into an energetic side-view running cycle, facing RIGHT in ALL frames. Exactly EIGHT distinct consecutive frames of ONE seamless run cycle: extension, contact, compression, passing, opposite extension, contact, compression, passing. Legs actually stride and tail bobs smoothly. Keep identical character proportions, palette, pixel scale and ground baseline in every frame; all four legs visible as appropriate. Sheet layout: EXACTLY FOUR equal-width columns by TWO equal-height rows, row-major chronological frame order, each frame centered in its equal rectangular cell with generous transparent gutters. Aim for a 1024 x 512 canvas; equal cells. No grid lines, no labels, no text, no drop shadows, no ground, no extra cats inside any cell, no sitting frames, no scenery, no blur, no antialiasing. True transparent background throughout all empty areas. Every cat must be fully inside its own cell with ample margins so this sheet can be cut into eight uniform cells and displayed at 24–32 pixels high.

> Create a production sprite sheet for the EXACT cute purple pixel BAT shown in the reference: front-facing squat violet body, two tiny upright ears, black-purple square eyes and little rectangular mouth, pink cheeks, lavender bat wings with dark navy stepped pixel outline. Preserve the charming face, purple palette and blocky retro pixel-art identity. EXACT layout: FOUR equal columns by TWO equal rows, EIGHT cells total, one bat centered fully inside each cell with generous transparent gutters. TOP ROW (4 cells) is a seamless flying wing-flap cycle, all facing FRONT: (1) wings raised, (2) wings spread horizontal, (3) wings lowered, (4) wings spread horizontal again. Keep the BODY and FACE identical in position, size and expression; only wings move. BOTTOM ROW (4 cells) is a stationary hover reaction with identical half-spread wings in all four cells: (1) eyes open looking straight at viewer, (2) eyes half closed, (3) both eyes completely closed as dark pixel lines, (4) eyes open again. Keep bottom-row body, wings and feet exactly stationary across its four cells; only eye pixels change. All cells have same pixel scale and centered body anchor. Pixel art for a small desktop UI pet displayed at roughly 36 pixels wide: crisp simple pixel blocks, limited palette, no blur, no antialiasing. Real transparent background. NO text, labels, question marks, grid lines, shadows, scenery, white background or extra characters. Desired wide canvas 1536x768 with 4x2 equal cells.
